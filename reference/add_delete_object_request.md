# Add a delete object request

Add a delete object request

## Usage

``` r
add_delete_object_request(google_slides_request = NULL, object_id)
```

## Arguments

- google_slides_request:

  A `GoogleSlidesRequest` object, or `NULL`.

- object_id:

  ID of the object to delete.

## Value

A `GoogleSlidesRequest` object with the request appended.
