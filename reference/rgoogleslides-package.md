# rgoogleslides: R Interface to the 'Google Slides' API

Provides an R interface to the 'Google Slides' API
<https://developers.google.com/slides/api>. Create presentations, add
slides, insert text, tables, images, and videos programmatically from R.
Designed for reproducible reporting workflows where analysis results
need to be pushed directly into 'Google Slides' presentations.
